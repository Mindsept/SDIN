L'énergie consommée par le logiciel (kWh)

Le principe

Un bon pattern se justifie deux fois

La sobriété n'est pas une contrainte ajoutée : c'est une propriété des bonnes architectures, qu'on n'avait pas l'habitude de nommer.

  • D'abord : simplicité, sécurité, résilience, coût
  • Ensuite : le calcul évité, mesurable
  • Une règle qui n'a pas les deux est suspecte
Qualité d'architecture
Le pattern se défend sans l'écologie
Calcul évité
Et il fait économiser du compute
Vérifiable
Une machine sait le contrôler

L'IA sous budget de calcul

Les apps n'appellent jamais un fournisseur en direct : une passerelle choisit le modèle et compte les tokens.

  • Des alias de modèles : task:cheap par défaut
  • Un budget par app : 50 000 tokens / 60 s, au-delà 429
  • Le RAG dans le Postgres existant (pgvector)
